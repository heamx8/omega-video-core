# Contributing

Use Node.js 20+ and run npm test and npm run demo before submitting changes. There is no install step.

Prefer small changes with synthetic reproductions. Keep planning functions deterministic and avoid hidden I/O. Preserve source timing and surface unsupported operations explicitly. Do not introduce a network service or model dependency into the offline core.

Do not include personal media, real project paths, transcripts, credentials or proprietary assets in issues, examples or tests. Contributions are made under the repository's GPL-3.0-only license; retain attribution for any third-party work and identify its license.
