# Security and privacy

Never post credentials, private media or customer timelines in a public issue. Use synthetic data for ordinary bugs. If GitHub private vulnerability reporting is available, use it for sensitive findings; otherwise describe only the need for private contact without disclosing exploit details or personal data.

This core does not connect to an editor or a network. An integrating application must validate input, recheck its live context and permissions, preserve backups, and verify execution. A mathematically consistent plan is not proof of an editor's successful execution.
